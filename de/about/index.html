The Science

IQ Test (Fluid Intelligence)

40 questions across number series (sequential reasoning), visual matrix patterns (spatial intelligence), and number analogies (relational thinking). Scored on standard IQ scale: mean 100, SD 15.

Reaction Time

Based on simple visual reaction time research. Average adult response: 250–270ms. Distribution data from Jain et al. (2015) across 50,000+ participants.

Working Memory (Digit Span)

Miller's (1956) foundational research: humans hold 7±2 items in working memory. The digit span subtest is part of clinical IQ assessments (WAIS, WISC).

Big Five Personality

Questions adapted from the IPIP Big-Five Factor Markers (Goldberg, 1992). The OCEAN model is the most replicated personality framework in psychology.

Stroop Effect (Focus)

First described by J.R. Stroop (1935). The interference effect measures executive function and cognitive control — a reliable predictor of working memory capacity.
