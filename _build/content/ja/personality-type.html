この性格タイプ診断で測るもの

この無料の16タイプ性格診断では、INTJやESFPのような4文字のコードが得られます。これはMyers-Briggs Type Indicatorによって広まった形式です。各文字は対になった一方の側を表します。外向か内向（E/I）、感覚か直観（S/N）、思考か感情（T/F）、判断か知覚（J/P）です。これらの考え方は、カール・ユングの著書『心理学的類型』（1921年）にさかのぼります。

多くの無料タイプ診断とは異なり、このテストは作られた質問ではなく、公開された研究用項目で採点され、文字だけでなく各文字にどの程度強く傾いているかも示します。

テストの仕組み

  • IPIPからの48項目。項目は、研究品質の性格項目を無料で集めたInternational Personality Item Poolの一部であるBig Five Aspect Scalesから取られています。
  • 各文字は対応するBig Five特性から採点されます。McCraeとCosta（1989）は468人の成人を対象に、マイヤーズ・ブリッグスの4つの尺度が別の名前でBig Fiveの4つの特性を測っていることを示しました。外向と内向はBig Fiveの外向性に、直観は開放性に、感情は協調性に、判断は誠実性に対応します。
  • 文字の対ごとに10項目。約半数は逆向きの表現になっているため、すべてに同意しても結果が一方に偏ることはありません。
  • 感情の反応性を測る5つ目の尺度。Big Fiveには、ストレスにどれだけ強く反応するかを表す神経症傾向も含まれますが、マイヤーズ・ブリッグスの体系ではこれが省かれています。8項目で測定し、文字は付けずに別に表示します。

各対の割合は、その対の項目に対するあなたの平均回答を0から100の尺度に換算したものです。50を超えると対の最初の文字、それ未満なら2番目の文字になります。

文字の意味

EかIか：エネルギーをどこから得るか

外向的な人は社交的でおしゃべりで、すぐに行動します。内向的な人は控えめで、エネルギーを回復するために一人の時間を必要とし、話す前に考えることがよくあります。内向は人見知りとは違います。

SかNか：何に注意を向けるか

感覚タイプは具体的な事実や実際の経験に注目します。直観タイプはアイデア、パターン、芸術、抽象的な問題に惹かれます。Big Fiveの用語では、この対は経験への開放性に対応します。

TかFか、JかPか

思考タイプは論理で決め、客観的でいられます。感情タイプは人への影響を重視します。判断タイプは計画、秩序、決着を好み、知覚タイプは選択肢を残して状況に合わせて対応します。この2つの対は協調性と誠実性に関係しています。

文字だけでなく割合も表示する理由

性格タイプに対する最大の科学的批判は、人はどの次元でも2つのはっきりしたグループには分かれないという点です。身長や体重と同じく、ほとんどの人は中間付近にいて、両端にいるのはごく一部です。McCraeとCostaは、マイヤーズ・ブリッグスの尺度が人を本当のタイプに分けるという証拠を見つけられませんでした。

これが重要なのは、52%の人と48%の人はほぼ同じなのに、違う文字が付いてしまうからです。同じ人がタイプ診断を受け直すと別のタイプになることが多い主な理由はこれで、Boyle（1995）とPittenger（2005）がこれを検討しています。そのためこのテストでは、すべての割合を表示し、文字が中間に近いときは知らせることで、タイプの各部分がどれだけ確かなものかがわかるようにしています。

  • 明確な傾向（75%超または25%未満）は、受け直しても変わりにくいです。
  • 中程度の傾向（60〜75%または25〜40%）は、たいてい維持されますが変わることもあります。
  • わずかな傾向（40〜60%）は、どちらの文字もほぼ同じくらいあなたに当てはまることを意味します。

タイプでわかること、わからないこと

4文字のタイプは、あなたが好む働き方、決め方、エネルギーの使い方について話すときに便利な略称です。同僚がすべてを計画する一方であなたが臨機応変に動く理由や、友人がパーティーの後に静かな時間を必要とする理由を説明する助けになります。能力、知能、心の健康を測るものではなく、どのタイプも他より優れているわけではありません。

文字は単純化されているため、心理学者は一般に、従業員の選考や仕事の成果の予測にタイプ診断を使うことを勧めていません。より完全な全体像を知りたい場合は、Big Fiveテストの5つの個別スコアのほうが、1つにまとめたコードよりも多くを教えてくれます。

正確な結果を得るには

  • ふだんの自分として答えてください。家でも職場でも、なりたい自分や、いつもと違う日の自分ではなく。
  • 中間の回答はなるべく控えましょう。少しでも一方に傾いているなら、そちらを選んでください。
  • 1つの文章を考えすぎないでください。最初の反応がたいてい最も正確です。
  • 別の日にもう一度受けてみましょう。いくつかの文字が50%に近い場合、どれが変わらないかを確かめられます。

よくある質問

これは公式のMBTIですか？

いいえ。Myers-Briggs Type Indicatorは商用の質問紙であり、The Myers-Briggs Companyの商標です。このテストは同じ4文字の枠組みを使いますが、無料で公開されている研究用項目で採点するため、あなたのタイプが公式レポートと異なる場合があります。

タイプは変わることがありますか？

性格は大人になるとかなり安定していますが、年月とともにゆっくり変化し、50%に近い文字はテストごとに入れ替わることがあります。タイプは固定されたラベルではなく、今の傾向を表すものと考えてください。

Big Fiveテストとはどう違いますか？

どちらも同じ基本的な特性を測っています。Big Fiveテストは5つの個別スコアを示し、このテストはそのうち4つを文字に変換して短いタイプ説明を加えます。Big Fiveのほうが詳しく、タイプのほうが覚えやすく共有しやすいです。
