工作记忆与数字广度任务

本测试采用认知心理学中经典的数字广度范式：在脑中保存一串不断变长的数字并将其复述出来。普通成年人大约能处理七加减二位数字，这就是米勒在一九五六年描述的著名神奇数字。工作记忆是推理能力、阅读理解和学业成绩最有力的单一预测指标之一。

如何解读你的广度

五到六位很常见，七到八位高于平均，九位及以上则相当出色。倒序广度，也就是反向复述，通常要短两位，对执行控制的负担也更重。

工作记忆可以提升吗 训练能提高所练任务的表现，把数字分组成块是一种非常有效的策略。但元分析显示，它向一般智力的迁移是有限的。睡眠和压力管理则会稳定地影响日常容量。

为什么用数字 在识字人群中数字具有文化中立性，易于随机生成，并且可以与数十年来发表的研究直接比较。
